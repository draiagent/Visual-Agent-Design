# Visual Agent Design｜可重複研究程序

## 1. 研究目的

比較不同任務介面與完整 VAD 方法論，對多模態 AI Agent 任務績效、使用者理解、認知負荷與人機共享理解的影響。

## 2. 標準任務

至少涵蓋五類：

1. 影片剪輯
2. 簡報製作
3. 網站生成
4. 數據分析
5. 文件 / 報告製作

每類任務需建立固定素材包、輸出規格與驗收表。

## 3. 實驗分組

| 組別 | 任務介面 | 目的 |
|---|---|---|
| A | 素材 + 純文字提示詞 | 基準組 |
| B | 素材 + VAC | 圖卡效果 |
| C | 素材 + VAC + 少量文字 | 圖文混合效果 |
| D | 素材 + 與 VAC 等資訊量的文字 SOP | 控制資訊完整度 |
| E | 素材 + 裝飾型圖卡 | 控制純美觀效果 |
| F | TRC-3D + VAC + Agent | 驗證完整 VAD |

關鍵比較：

- B vs D：視覺結構效果
- C vs B：少量文字補充效果
- F vs C：任務路由效果

## 4. 客觀指標

### 任務完成率

`通過驗收項目數 ÷ 全部驗收項目數 × 100%`

### 首次通過率

第一次輸出即通過驗收的比例。

### 修改次數

每一次實質內容 / 規格修正要求記為一次；系統錯誤重試與單純確認不計。

### 操作時間

分開記錄：

- T1：使用者理解與準備時間
- T2：Agent 首次執行時間
- T3：人工修正至驗收通過時間

並區分人工主動時間與系統 / Agent 等待時間。

### 加權錯誤分數

`Critical × 5 + Major × 3 + Minor × 1`

### 成果一致性

同一任務重複執行，評估結構、內容、品牌、格式與驗收結果一致性。

## 5. 主觀量表

### TUS-VA｜任務理解

測量目標、素材、流程、規則、輸出與驗收理解。

### Cognitive Load｜認知負荷

至少區分：內在負荷、外在負荷、有效學習負荷。

### HASTU｜人機共享任務理解

測量：

- AI 是否理解最終目標
- 人與 AI 對流程是否一致
- AI 是否能辨識優先級
- AI 是否能合理處理例外
- 輸出是否符合使用者心智模型
- 人與 AI 對完成條件是否一致

### 易用性與滿意度

測量易學、易操作、提示詞依賴、軟體依賴、再使用意願與推薦意願。

## 6. 標準程序

### Phase 0｜預註冊

事先固定研究假設、樣本數、分組方式、排除條件、主要指標、統計方法、模型版本、工具權限與任務素材。

### Phase 1｜參與者篩選

記錄 AI 經驗、提示詞經驗、視覺工具經驗、教育背景與任務相關專業程度。

### Phase 2｜前測

測量 AI 基本能力、任務知識、視覺理解與自我效能。

### Phase 3｜分層隨機分派

可依 AI 使用經驗分層，確保各組起點接近。

### Phase 4｜統一說明

主持人使用固定逐字稿；不得對特定組別額外解釋、提示或協助。

### Phase 5｜任務執行

固定同一模型版本、素材、工具權限、時間限制、設備條件與對話起始狀態。

完整記錄所有輸入、Agent 回覆、工具調用、修改、系統錯誤與最終輸出。

### Phase 6｜盲評

至少兩位不知道組別來源的評分者使用同一驗收表獨立評分。

### Phase 7｜後測

測量任務理解、認知負荷、HASTU、易用性與滿意度。

### Phase 8｜延宕測驗

建議 7 天後使用相似但不同內容的新任務，檢驗學習保留與方法遷移。

## 7. 研究控制

- A/B/C/D 組的核心資訊量應盡量等值。
- C 組「少量文字」需預先定義，例如不超過 100 字、最多 3 項補充。
- 修改次數上限應固定，例如最多 3 次實質修正。
- 模型與平台版本需記錄日期與版本資訊。
- 素材檔名、格式、順序與內容需一致。

## 8. 信度與效度

建議：

- 5–10 位跨領域專家進行內容效度審查。
- 30–50 人先行預試。
- 檢查量表內部一致性。
- 對成果盲評檢查評分者一致性。
- 驗證任務理解、易用性、HASTU、認知負荷與滿意度的建構區辨。

## 9. 核心研究假設

- H1：VAC 組任務完成率高於純文字組。
- H2：VAC 組修改次數低於純文字組。
- H3：VAC 組人工操作時間低於純文字組。
- H4：VAC 組初學者理解度較高。
- H5：VAC 組成果一致性較高。
- H6：VAC 組錯誤率較低。
- H7：VAC 組使用滿意度較高。
- H8：VAC + 少量文字優於純 VAC。
- H9：正確 TRC-3D 路由提升 Agent 任務績效。
- H10：人機共享任務理解在 VAC 與績效間具有中介效果。
