# VAC-VIDEO-001-V1.0｜AI 短影音剪輯範例

## 01｜Task Goal

- 任務：將 3–5 分鐘原始影片製作成 60 秒直式短影音
- 受眾：一般社群使用者
- 完成定義：輸出可正常播放、9:16、繁體中文字幕、通過驗收表

## 02｜Input Assets

### Required

- 原始影片
- 逐字稿
- Logo

### Optional

- 補充圖片
- 背景音樂
- 參考圖卡

### Missing Asset Policy

- 缺原始影片：停止
- 缺逐字稿：若環境支援語音辨識則先轉錄
- 缺 Logo：可輸出無品牌預覽版，但不得假造 Logo
- 缺背景音樂：輸出無音樂版

## 03｜Process Flow

| Step | Action | Input | Output | Checkpoint |
|---|---|---|---|---|
| P01 | 檢查素材 | 全部檔案 | 素材清單 | Required 是否完整 |
| P02 | 對齊語音與逐字稿 | 影片、逐字稿 | 校正文本 | 主旨與時間軸一致 |
| P03 | 建立剪輯主線 | 校正文本 | 60 秒內容結構 | 無重複主旨 |
| P04 | 建立粗剪 | 原始影片 | 粗剪版本 | 長度接近 60 秒 |
| P05 | 加入圖片 / Logo | 粗剪、圖像 | 品牌版本 | 不遮擋重要主體 |
| P06 | 製作字幕 | 校正文本 | 字幕版本 | 繁中、同步 |
| P07 | 混音 | 語音、音樂 | 混音版本 | 人聲清楚 |
| P08 | 完整驗收與輸出 | 完成版 | MP4 | 全項通過 |

## 04｜Tools & Capabilities

- 語音轉錄能力：Whisper 或等效工具
- 影片剪輯能力：FFmpeg 或等效工具
- 圖像處理能力：Pillow / ImageMagick 或等效工具
- 內容整理能力：多模態 / 語言模型

## 05｜Decision Rules

```text
IF 逐字稿與實際語音不一致
THEN 以實際語音為主並修正字幕

IF 初剪超過 60 秒
THEN 優先刪除重複語句、停頓與次要例子

IF 背景音樂影響人聲辨識
THEN 降低音樂音量或移除音樂

IF 圖片與內容無明確關聯
THEN 不強制插入
```

## 06｜Constraints

### Critical

- 不可捏造未出現在素材中的重要事實
- 影片必須可以正常解碼播放
- 不得讓背景音樂壓過主要人聲

### Major

- 使用繁體中文字幕
- Logo 不得拉伸變形
- 內容主旨不得因剪輯而反轉

### Minor

- 轉場與動畫保持簡潔

## 07｜Output Specification

- 格式：MP4
- 比例：9:16
- 解析度：1080 × 1920
- 長度：45–60 秒
- 字幕：內嵌繁體中文
- 音訊：人聲優先
- 命名：`VAC_VIDEO_001_V1.mp4`

## 08｜Acceptance Criteria

- [ ] 可完整播放
- [ ] 無黑畫面或破損片段
- [ ] 45–60 秒
- [ ] 音畫同步
- [ ] 中文字幕與語音一致
- [ ] 無明顯繁體中文錯字
- [ ] Logo 正確且未變形
- [ ] 背景音樂未蓋過人聲
- [ ] 主旨與來源內容一致
