# VAC-SOCIAL-001-V1.0｜社群貼文製作

> Tier：Extended（非 Standard VAC Five-Pack 核心五卡）
>
> **本卡是全註冊表中唯一 `human_review.required = true` 的卡。** 產製可以自動化，
> 發布不行——貼出去是不可逆的外部行為，一律由人按下最後那一鍵。

## 01｜Task Goal

- 任務：依平台規格產出社群貼文的視覺與文案
- 受眾：依輸入指定，預設為在動態牆快速滑動的讀者
- 目標：前兩行就留住讀者，並帶出明確行動
- 完成定義：輸出各指定平台尺寸的圖檔與文案，通過所有 Critical 驗收項目

## 02｜Input Assets

### Required

- 貼文主題或要傳達的訊息

### Optional

- 平台清單
- 品牌 token 或色彩字型規範
- 圖像素材、指定 CTA、hashtag 策略
- 目標受眾、資料來源

### Missing Asset Policy

- 缺平台：預設 Instagram 1:1，並於交付時說明
- 缺品牌規範：採中性高對比版型，不自行創造品牌色
- 缺 CTA：依貼文目的補一個明確行動，不留空
- 缺圖片：以排版、圖示與色塊替代，不使用來源不明的圖片

## 03｜Process Flow

| Step | Action | Input | Output | Checkpoint |
|---|---|---|---|---|
| P01 | 讀取需求 | 全部素材 | 任務摘要 | 主題、平台、受眾、目的清楚 |
| P02 | 決定平台與尺寸 | 任務摘要 | 尺寸清單 | 各平台比例與安全區確定 |
| P03 | 撰寫文案 | 摘要、CTA | 主文案與變體 | 前兩行有鉤子、有明確 CTA |
| P04 | 設計視覺 | 文案、尺寸、素材 | 各尺寸視覺 | 重要元素都在安全區內 |
| P05 | 套用品牌 | 視覺、token | 品牌版貼文 | 色彩、字級、留白一致 |
| P06 | 輸出與檢查 | 品牌版貼文 | 圖檔、文案檔 | 全項驗收 |

## 04｜Tools & Capabilities

- 社群文案撰寫：LLM 或等效工具
- 版面輸出：設計工具、HTML 轉圖或等效方案
- 文字校對：校對工具或等效方案
- 品牌 token 套用、AI 圖像生成：選用

## 05｜Decision Rules

- 未指定平台 → 預設 IG 1:1 並說明
- 跨多平台 → 依平台重新排版與改寫，**不把同一張圖硬套所有尺寸**
- 文案過長 → 拆成本文與留言補充，不縮字級
- 缺 CTA → 依目的補一個明確行動
- 素材授權或肖像同意不明 → **停止並回報，不先做再確認**
- 數據無來源 → 標示待查證，不當事實呈現

## 06｜Constraints

- **Critical**：不得捏造來源、引用或數據
- **Critical**：不得使用未授權素材，或未經同意的個人資訊與肖像
- **Critical**：輸出檔案必須可正常開啟
- **Major**：重要文字與元素必須落在平台安全區內
- **Major**：文案前兩行必須留住讀者，不用開場白浪費
- **Major**：使用繁體中文
- **Minor**：hashtag 克制且相關

## 07｜Output Specification

- 格式：PNG（各平台尺寸）＋ TXT（各平台文案）
- 尺寸：IG 1:1／4:5、限動 9:16、Facebook 1.91:1、LinkedIn 1.91:1、Threads 1:1
- 語言：繁體中文
- 命名：`VAC_SOCIAL_001_v1_{platform}.png`／`.txt`

## 08｜Acceptance Criteria

- 每個指定平台都有對應尺寸的圖檔與文案
- 重要元素未被安全區外裁切或介面元件遮住
- 文案前兩行具備鉤子
- 有明確且與目的一致的 CTA
- 無明顯繁體中文錯字
- 整體風格與品牌一致
- **Critical**：數據與引用皆可追溯
- **Critical**：素材授權與肖像同意已確認
- **Critical**：輸出檔案皆可正常開啟

## Human Review

**必要。** 對外發布前由內容或品牌負責人覆核。本卡只負責產製；
實際發布屬於不可逆的外部行為，不在 Agent 的授權範圍內。
