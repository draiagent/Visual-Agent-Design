# VAC-REPORT-001-V1.0｜正式報告製作

## 01｜Task Goal

- 任務：產出 1 份 5–8 頁正式報告
- 目標：內容完整、結構清楚、可供決策參考
- 必要內容：摘要、分析、建議與行動項目
- 完成定義：DOCX 與 PDF 可正常開啟，內容無虛構引用並通過驗收表

## 02｜Input Assets

### Required

- 會議逐字稿或主要來源資料
- 背景資料

### Optional

- 參考文件
- 報告模板
- 品牌 Logo
- 目標讀者與用途
- 引用格式要求

### Missing Asset Policy

- 缺主要來源資料：停止
- 缺背景資料：可先整理逐字稿，但需明確標記資訊邊界
- 缺模板：採中性專業報告版型
- 缺 Logo：輸出無品牌版，不得假造 Logo
- 缺引用來源：標記待補，不得虛構引用

## 03｜Process Flow

| Step | Action | Input | Output | Checkpoint |
|---|---|---|---|---|
| P01 | 閱讀資料 | 全部來源 | 來源清單 | 來源可追溯 |
| P02 | 萃取重點 | 來源資料 | 重點摘要 | 無關鍵遺漏 |
| P03 | 建立章節 | 摘要、用途 | 報告架構 | 摘要／分析／建議／行動項目齊備 |
| P04 | 撰寫內容 | 架構、來源 | 初稿 | 每項主張有來源依據 |
| P05 | 統一格式 | 初稿、模板 | 完整版 | 標題、表格、引用一致 |
| P06 | 輸出與審核 | 完整版 | DOCX、PDF | 全項驗收 |

## 04｜Tools & Capabilities

- 摘要與資訊萃取
- 結構化長文撰寫
- 表格與行動項目整理
- 引用與註記管理
- DOCX / PDF 生成與版面檢查

## 05｜Decision Rules

```text
IF 資訊重複
THEN 合併並精簡，但保留不同來源的重要差異

IF 缺乏依據
THEN 標記待補或限制，不以推測補成事實

IF 篇幅過長
THEN 優先保留摘要、關鍵發現、建議與行動項目

IF 不同來源互相衝突
THEN 並列呈現差異與來源，不自行消除衝突
```

## 06｜Constraints

### Critical

- 不可虛構引用、數據或來源
- 不可把推測寫成已確認事實
- DOCX 與 PDF 必須可正常開啟

### Major

- 使用繁體中文
- 章節標題需清楚
- 語氣需客觀專業
- 建議必須具體且可執行
- 來源需可追溯

### Minor

- 格式、表格與標點需一致
- 避免不必要的修辭與贅字

## 07｜Output Specification

- 格式：DOCX + PDF
- 篇幅：5–8 頁
- 語言：繁體中文
- 結構：摘要、背景／目的、分析／發現、建議、行動項目
- 命名：`VAC_REPORT_001_v1.docx`、`VAC_REPORT_001_v1.pdf`

## 08｜Acceptance Criteria

- [ ] DOCX 可正常開啟
- [ ] PDF 可正常開啟
- [ ] 報告結構完整
- [ ] 關鍵資訊完整
- [ ] 無明顯繁體中文錯字
- [ ] 無虛構引用或來源
- [ ] 建議具體可執行
- [ ] 行動項目可被指派或追蹤
- [ ] 格式一致
