# VAC-SLIDE-001-V1.0｜專業簡報製作

## 01｜Task Goal

- 任務：製作 1 份 10 頁、16:9 的專業簡報
- 受眾：依輸入素材指定之目標受眾
- 目標：結構清楚、重點明確、適合簡報與教學
- 完成定義：輸出 PPTX 與 PDF，通過所有 Critical 驗收項目

## 02｜Input Assets

### Required

- 主題資料與重點文字
- 品牌 Logo（若任務要求品牌版）

### Optional

- 圖片或圖示素材
- 色彩與字型規範
- 參考版型
- 目標受眾資訊

### Missing Asset Policy

- 缺主題資料：停止並要求補件
- 缺 Logo：可輸出無品牌預覽版，不得假造 Logo
- 缺圖片：以合法圖示、圖表或留白結構替代
- 缺品牌規範：採保守、專業、可讀的中性版型

## 03｜Process Flow

| Step | Action | Input | Output | Checkpoint |
|---|---|---|---|---|
| P01 | 讀取需求 | 全部素材 | 任務摘要 | 目標與受眾清楚 |
| P02 | 整理架構 | 主題資料 | 10 頁故事線 | 有開場、主體、結論 |
| P03 | 撰寫大綱 | 故事線 | 每頁標題與重點 | 每頁單一主題 |
| P04 | 配置圖文 | 大綱、圖片、Logo | 初版簡報 | 圖文比例合理 |
| P05 | 統一版型 | 初版、品牌規範 | 品牌版簡報 | 色彩、字級、留白一致 |
| P06 | 輸出與檢查 | 品牌版 | PPTX、PDF | 全項驗收 |

## 04｜Tools & Capabilities

- 內容摘要與重組能力：LLM 或等效工具
- 簡報版面生成能力：PowerPoint / Slides / PPTX 產生工具或等效方案
- 圖表製作能力：試算表、Python 或等效工具
- 圖片處理能力：圖片裁切、壓縮與格式轉換工具
- PDF 輸出能力

## 05｜Decision Rules

```text
IF 內容過長
THEN 拆成多頁並保留主線，不把全文塞進單頁

IF 缺少圖片
THEN 以圖示、圖表、數據視覺或結構化排版替代

IF 品牌規範不完整
THEN 採保守專業版型，避免自行創造品牌色

IF 來源資料彼此衝突
THEN 標示衝突並停止自行定論
```

## 06｜Constraints

### Critical

- 不得捏造來源資料、引用或數據
- 檔案必須可正常開啟
- 關鍵品牌資產不得變形或錯用

### Major

- 使用繁體中文
- 每頁聚焦單一主要訊息
- 文字需清楚可讀，不可堆滿頁面
- 內容來源需可追溯

### Minor

- 動畫與裝飾保持克制
- 圖示風格保持一致

## 07｜Output Specification

- 格式：PPTX + PDF
- 比例：16:9
- 頁數：10 頁
- 結構：封面、目錄／導覽、正文、結論
- 語言：繁體中文
- 命名：`VAC_SLIDE_001_v1.pptx`、`VAC_SLIDE_001_v1.pdf`

## 08｜Acceptance Criteria

- [ ] PPTX 可正常開啟
- [ ] PDF 可正常開啟
- [ ] 頁數為 10 頁
- [ ] 整體結構清楚
- [ ] 無明顯繁體中文錯字
- [ ] 品牌風格一致
- [ ] 圖文配置平衡
- [ ] 每頁重點清楚
- [ ] 來源與數據沒有被虛構
