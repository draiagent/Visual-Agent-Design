# VAC-DATA-001-V1.0｜數據分析

## 01｜Task Goal

- 任務：產出 1 份可解讀、可重現的數據分析結果
- 目標：提供至少 3 張核心圖表、重點洞察與後續建議
- 受眾：管理者、研究者或業務決策者
- 完成定義：計算可重算、圖表標示完整、結論與資料一致

## 02｜Input Assets

### Required

- CSV 或 Excel 資料檔
- 欄位說明或資料字典
- 分析問題

### Optional

- 時間區間
- 統計需求
- 指標定義
- 分群條件
- 既有報表或比較基準

### Missing Asset Policy

- 缺資料檔：停止
- 缺欄位說明：先進行欄位掃描並標記不確定欄位，不自行猜測商業語意
- 缺分析問題：先提供描述統計與資料品質摘要，再要求明確問題
- 缺指標定義：不得自行發明企業 KPI 定義

## 03｜Process Flow

| Step | Action | Input | Output | Checkpoint |
|---|---|---|---|---|
| P01 | 匯入資料 | CSV / Excel | 原始資料表 | 檔案可讀、列欄數記錄 |
| P02 | 清理欄位 | 原始資料 | 清理資料 | 型別、缺值、重複值已處理 |
| P03 | 描述統計 | 清理資料 | 統計摘要 | 數值可重算 |
| P04 | 建立圖表 | 統計結果 | 至少 3 張圖表 | 標題、軸、單位完整 |
| P05 | 解讀發現 | 統計、圖表 | 洞察摘要 | 不超出資料證據 |
| P06 | 輸出報告 | 全部結果 | 清理檔、報告、圖表 | 全項驗收 |

## 04｜Tools & Capabilities

- 資料讀取與清理：Python / pandas、試算表或等效工具
- 統計分析：Python、R、試算表或等效工具
- 視覺化：Matplotlib、試算表圖表或等效工具
- 異常值與缺失值檢查
- 表格、摘要與報告輸出

## 05｜Decision Rules

```text
IF 缺值比例過高
THEN 先量化缺值比例，標示風險，再依分析目的決定刪除、補值或保留

IF 欄位格式異常
THEN 先標準化型別、日期、單位與編碼，再進行分析

IF 結果不顯著或無明顯趨勢
THEN 忠實呈現，不過度推論

IF 發現可能的異常值
THEN 先標示並進行敏感度檢查，不直接刪除
```

## 06｜Constraints

### Critical

- 不得捏造數據
- 計算公式與單位必須一致
- 結論不得超出資料證據
- 涉及個資時必須依規則遮蔽或去識別

### Major

- 分析過程需可重現
- 缺值與異常值處理需留下紀錄
- 圖表標題、軸、單位與圖例需完整

### Minor

- 圖表風格應一致
- 不使用不必要的 3D 圖表或裝飾

## 07｜Output Specification

- 清理資料：XLSX 或 CSV
- 分析摘要：Markdown / DOCX / PDF 任一可讀格式
- 圖表：至少 3 張
- 必要內容：資料品質、描述統計、核心洞察、限制、建議
- 命名：`VAC_DATA_001_v1.xlsx` 與 `VAC_DATA_001_report_v1.md` 或等效格式

## 08｜Acceptance Criteria

- [ ] 原始列數、清理後列數有紀錄
- [ ] 主要計算結果可重算
- [ ] 缺值處理有說明
- [ ] 異常值處理有說明
- [ ] 至少 3 張核心圖表
- [ ] 圖表標示完整
- [ ] 結論與數據一致
- [ ] 無明顯公式或單位錯誤
- [ ] 輸出檔案可正常開啟
