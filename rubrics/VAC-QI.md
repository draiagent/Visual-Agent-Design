# VAC-QI｜Visual Agent Card Quality Index

採 5 點量尺：1 完全不符合、2 大部分不符合、3 部分符合、4 大部分符合、5 完全符合。

## A｜目標明確性 Goal Clarity

1. 圖卡清楚說明最終任務成果。
2. 任務目標可以被客觀檢查。
3. 圖卡沒有互相衝突的主要目標。

## B｜素材完整性 Input Completeness

4. 圖卡清楚列出必要輸入素材。
5. 圖卡可以區分必要與選用素材。
6. 圖卡說明素材缺漏時的處理方式。

## C｜流程可理解性 Process Comprehensibility

7. 執行步驟具有清楚順序。
8. 每個步驟使用明確的動作描述。
9. 流程中的輸入與輸出關係清楚。

## D｜視覺結構性 Visual Structure

10. 重要資訊具有明確視覺層級。
11. 箭頭、編號及區塊不易造成誤解。
12. 圖文配置有助於快速掌握任務全貌。

## E｜決策充分性 Decision Sufficiency

13. 圖卡包含重要例外情況的處理方式。
14. 圖卡清楚設定不同條件下的優先順序。
15. Agent 遇到素材衝突時有判斷依據。

## F｜規格精確性 Specification Precision

16. 輸出格式與尺寸清楚。
17. 品牌、語言及技術要求清楚。
18. 關鍵數值及限制沒有模糊空間。

## G｜可執行性 Executability

19. Agent 可根據圖卡安排實際步驟。
20. 圖卡提供足夠資訊完成任務。
21. 圖卡內容能轉換成具體操作。

## H｜可驗收性 Verifiability

22. 圖卡清楚說明完成條件。
23. 驗收標準可以被不同評分者一致使用。
24. 成果失敗時可以確認問題所在階段。

## 計分

```text
VAC-QI = 24 題總分
最低 24；最高 120
```

初版解讀：

| 分數 | 等級 | 解讀 |
|---:|---|---|
| 101–120 | A | 可直接正式執行 |
| 81–100 | B | 可執行，少量修正 |
| 61–80 | C | 資訊不足，需優化 |
| 41–60 | D | 難以穩定執行 |
| 24–40 | E | 不符合 VAC 標準 |

> 注意：上述分級是方法論初版門檻，不是已建立的統計常模；正式研究後應依樣本分布與效度分析重新校準。
